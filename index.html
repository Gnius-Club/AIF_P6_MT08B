🎯 Objetivo de Aprendizaje

Los estudiantes podrán: Comprender la importancia de la planificación de trayectorias y el control de errores, y usar el XGO y Python para programar secuencias de traslación y giros controlados que permitan planificar una trayectoria completa de ida y vuelta.

🤖 Prompt de Referencia para XOLO (Solo para Maestro)

⚠️ NOTA: XOLO ya conoce el tema de esta misión. Este prompt es SOLO de referencia en caso de emergencia técnica: 
Quiero aprender a diseñar una misión completa de navegación con retorno usando Python. Explícame qué significa “planificar una trayectoria” y por qué un robot necesita pensar en el camino de regreso. Luego enséñame a usar xgo.translation(x,y,z,step_length,time) para moverse con precisión (incluyendo desplazamiento lateral o diagonal) y xgo.rotate_right(speed) para orientar el cuerpo antes de avanzar. Guíame para construir una secuencia estructurada: salida → avance → giro → retorno → alineación final. Incluye protocolos de seguridad: pausas para estabilizar, límites de velocidad, y cómo corregir si el robot se desvía.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a idear en Python una misión donde el XGO complete una operación de rescate y regrese a una “zona segura”. Quiero que tenga una vibe de “robot cuidadoso” que siempre verifica su orientación antes de moverse. Primero diseña la ruta en pasos, luego tradúcela en código con pausas y control de velocidad. Después genera el código en Python para ejecutarlo, de acuerdo a tu entrenamiento con el robot XGO y Micro:bit, incluyendo una forma simple de verificación (ej: repetir una secuencia si se desvió o agregar un “checkpoint” con una tarjeta)."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿El XGO regresa exactamente al punto donde comenzó?
  • ¿Qué pasa si aumentas la velocidad del XGO durante el retorno?
  • ¿Funciona igual la trayectoria si el suelo es liso vs. si tiene obstáculos?
  • ¿Por qué es vital planificar la trayectoria antes de que el robot empiece a moverse?
  • Si el robot se desvía un poco en cada paso, ¿qué tipo de error se está acumulando y cómo lo controlarías?

¡Es hora de crear! Vamos a diseñar una misión de rescate completa. Primero, platiquen con XOLO para idear una ruta y darle un 'VIBE' de robot cuidadoso. Él les dará un GCS que luego pasarán a bloques en MakeCode. Por ejemplo, podrían programar al XGO para que entre en una zona de peligro, haga una pausa para 'rescatar' un objeto imaginario y luego use una secuencia precisa de giros y traslaciones para volver a la zona segura. Prueben primero en el simulador y, cuando estén listos, les entregaré el hardware. Si tienen errores o dudas, pregúntenle a XOLO, él los ayudará a depurar. ¡No olviden las preguntas de experimentación al final!
